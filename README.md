# 💳 Прогнозирование кредитного скоринга с помощью CatBoost

## 🎯 Описание проекта
Данный проект направлен на классификацию клиентов банка по трем категориям надежности: **Good** (Хороший), **Standard** (Средний) и **Poor** (Низкий). Основная бизнес-цель — минимизация рисков выдачи кредитов ненадежным клиентам (снижение ошибок, при которых клиент `Poor` классифицируется как `Standard` или `Good`).

## 🛠 Технологический стек
* **Язык**: Python
* **Модель**: CatBoostClassifier
* **Библиотеки**: Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib
* **Инструменты**: GridSearchCV (для оптимизации параметров)

## 📋 Этапы работы

### 1. Предобработка данных (Preprocessing)
* Проведена очистка данных от специфических символов (функция `transform_data`).
* Выполнена фильтрация выбросов по ключевым признакам: `Annual_Income`, `Num_of_Loan`, `Outstanding_Debt` и др.
* Категориальные признаки обработаны для корректной работы с градиентным бустингом.

### 2. Отбор признаков
* Проведен корреляционный анализ для исключения мультиколлинеарности.
* Признаки с низкой значимостью были удалены для повышения обобщающей способности модели.

### 3. Обучение и настройка
* Использование **CatBoost** позволило эффективно работать с пропусками и категориями без сложного кодирования.
* Для борьбы с дисбалансом применены веса классов (`class_weights`).
* Оптимизация проведена через кросс-валидацию.

## 📊 Результаты и метрики

### Отчет по классификации (Classification Report)
| Класс | Precision | Recall | F1-Score |
| :--- | :---: | :---: | :---: |
| **Good** | 0.60 | 0.91 | 0.72 |
| **Poor** | 0.76 | 0.86 | 0.81 |
| **Standard** | 0.91 | 0.68 | 0.78 |

> **Accuracy модели**: ~0.775

### Матрица ошибок (Confusion Matrix)
Матрица визуализирует распределение ошибок. Особое внимание уделено строке `Poor`: модель успешно идентифицирует **86%** потенциально проблемных заемщиков.



### ROC-AUC Анализ
ROC-кривые построены для каждого класса отдельно (One-vs-Rest). Высокие значения площади под кривой (AUC) подтверждают высокое качество ранжирования клиентов по степени риска.

## 💡 Выводы
1. Модель демонстрирует высокую полноту (**Recall 0.86**) по самому рискованному классу `Poor`, что отвечает требованию безопасности банка.
2. Высокая точность (**Precision 0.91**) в классе `Standard` позволяет автоматизировать большинство решений по "средним" клиентам.
3. Для дальнейшего улучшения рекомендуется работа над Precision класса `Good`, чтобы уменьшить количество ложных отказов надежным клиентам.
